## `01` Projects

### [HotelScout](https://github.com/EricKColl/hotelscout) · hotel finder PWA

Progressive Web App that finds real accommodation near a station, an airport or an address using OpenStreetMap data, with an interactive map, filters, favourites and a Booking.com search link — no accounts, no trackers, €0 running cost.

### [Forja](https://github.com/EricKColl/LeriFitness) · personal gym training PWA

Local-first PWA for personalised gym training: workout plans generated by a deterministic, fully tested rule engine based on evidence-backed training principles — no AI decides your plan. Works offline, installs from the browser and keeps health data on your device, with an interactive 3D anatomy model and optional cloud sync.

<a href="https://github.com/EricKColl/LeriFitness"><img src="assets/modules/forja.svg" width="100%" alt="Forja architecture: React 19 interface → deterministic rule engine in TypeScript → IndexedDB on the device, with optional Supabase sync, lazy-loaded 3D anatomy and an on-device AI glossary."></a>

<img src="assets/ui/badge-live.svg" height="20" alt="Live"> **[forja-13u.pages.dev →](https://forja-13u.pages.dev)** · [Source](https://github.com/EricKColl/LeriFitness) (repo: LeriFitness) · [CI](https://github.com/EricKColl/LeriFitness/actions/workflows/ci.yml) · [Production smoke tests](https://github.com/EricKColl/LeriFitness/actions/workflows/smoke.yml)<br>
<sub>Rule engine in pure TypeScript with tests · offline PWA (Workbox) · optional Supabase sync (EU, RLS, no health data) · React · TypeScript · Vite · Tailwind CSS · Three.js · IndexedDB (Dexie) · Supabase · Vitest · PWA</sub>
