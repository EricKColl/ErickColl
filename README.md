Two products in production, and the team systems that taught me how to build them — each product line grown version after version.

<a href="https://github.com/EricKColl/hotelscout"><img src="assets/modules/hotelscout.svg" width="100%" alt="Module 01 — HotelScout, hotel finder PWA, live at hotelscout.pages.dev. <sub>React · TypeScript · Vite · Tailwind CSS · Leaflet · Cloudflare Pages · PWA</sub> &nbsp; <img src="assets/ui/badge-live.svg" height="20" alt="Live"> **[hotelscout.pages.dev →](https://hotelscout.pages.dev)**

<a href="https://github.com/EricKColl/LeriFitness"><img src="assets/modules/forja.svg" width="100%" alt="Module 02 — Forja, personal gym training PWA, live at forja-13u.pages.dev. Architecture: React 19 interface → deterministic rule engine in pure TypeScript → local IndexedDB data with Dexie, Zustand and Zod; optional modules: Supabase sync (EU, RLS, no health data), lazy-loaded 3D anatomy with three.js, on-device AI glossary with WebLLM. Stack: React 19, TypeScript, Vite, Tailwind CSS 4, Three.js, Dexie, Supabase, Vitest, PWA."></a>

**[Forja](https://github.com/EricKColl/LeriFitness)** — Local-first PWA for personalised gym training: workout plans generated by a deterministic, fully tested rule engine based on evidence-backed training principles — no AI decides your plan. Works offline, installs from the browser and keeps health data on your device, with an interactive 3D anatomy model and optional cloud sync.<br>
<sub>React · TypeScript · Vite · Tailwind CSS · Three.js · IndexedDB (Dexie) · Supabase · Vitest · PWA</sub> &nbsp; <img src="assets/ui/badge-live.svg" height="20" alt="Live"> **[forja-13u.pages.dev →](https://forja-13u.pages.dev)**
